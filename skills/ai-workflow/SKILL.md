# AI Workflow Skill


Treat AI as an engineering system.

## Context hierarchy
1. Global rules
2. Project rules
3. Task-specific skill
4. Specialist agent
5. Retrieved documentation/data

Keep stable rules short.

## Model routing
Use strong reasoning models for architecture, security, difficult debugging, and final reviews.
Use local models for bulk summarization, transformations, private data processing, and cheap iteration when quality is sufficient.

## Memory
Store durable facts, decisions, and progress—not secrets and not noisy transcripts.
