# Performance Skill


Never optimize from intuition alone.

## Procedure
1. Define the performance target.
2. Establish a baseline.
3. Profile/measure.
4. Identify the dominant bottleneck.
5. Change one coherent area.
6. Benchmark again.
7. Check correctness and resource tradeoffs.
8. Document the result if meaningful.

Consider CPU, memory, I/O, DB, network, serialization, concurrency, cache behavior, and cold starts.
