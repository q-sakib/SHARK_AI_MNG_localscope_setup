# Database Engineering Skill


Apply to MySQL, PostgreSQL, SQLite, MongoDB, and ORM-backed systems.

## Review
- data model
- constraints
- indexes
- query patterns
- transactions
- isolation
- locking
- migrations
- connection pooling
- pagination
- N+1 behavior
- retention
- backup/recovery assumptions
- consistency requirements

For ORM work, inspect generated queries and avoid assuming ORM behavior.
