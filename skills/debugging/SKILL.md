# Debugging Skill


Do not patch symptoms blindly.

Procedure:
1. Capture exact error.
2. Reproduce.
3. Trace execution and dependencies.
4. Form hypotheses.
5. Test the highest-probability hypothesis.
6. Identify root cause.
7. Implement smallest correct fix.
8. Add regression protection.
9. Re-run relevant checks.

Separate environment/configuration failures from application defects.
