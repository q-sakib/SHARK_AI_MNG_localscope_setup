# Architecture Decision Skill


Use for new systems, major refactors, protocol choices, service boundaries, or scaling decisions.

## Procedure
1. Discover current structure and constraints.
2. Identify functional and non-functional requirements.
3. Establish expected scale and failure model.
4. Produce 2-3 viable architecture options.
5. Compare complexity, performance, security, operability, cost, and migration risk.
6. Recommend one option.
7. Implement only after the decision is explicit.
8. Record durable decisions in an ADR.

## Required output
- Goal
- Constraints
- Current state
- Options
- Tradeoff matrix
- Recommendation
- Migration/rollback plan
- Validation plan
