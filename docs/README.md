# Project Documentation

## Sections

- `architecture/` — system and component architecture
- `api/` — API contracts and integration documentation
- `database/` — schema, migrations, and data design
- `deployment/` — build and deployment procedures
- `development/` — local development guides
- `troubleshooting/` — known problems and fixes
- `decisions/` — Architecture Decision Records (ADRs)

## Documentation Rule

Keep durable project knowledge here. Keep behavioral instructions in `CLAUDE.md`, repeatable workflows in `.claude/skills/`, and major architectural decisions in ADRs.
